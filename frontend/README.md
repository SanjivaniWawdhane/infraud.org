# 🛡️ INFRAUD.org — Check Before You Trust

![INFRAUD Hero Banner](https://res.cloudinary.com/dbnhczmid/image/upload/v1791460909/Screenshot_2026-10-08_173153_ib1g6q.png)

**INFRAUD** is a modern, fast, and responsive web application designed to help users verify suspicious websites, phone numbers, UPI IDs, and messages instantly. In a world full of digital scams, INFRAUD acts as your first line of defense to check before you trust.

🔗 **Live Demo:** [infraud.org](https://infraud.org) _(Update this link if you have a live domain!)_

---

## 🚀 Features

- 🌐 **Website Verification**: Analyze URLs to check if they are phishing links or legitimate sites.
- 📱 **Phone Number Lookup**: Identify potential scam callers and spam numbers.
- 💳 **UPI ID Checker**: Ensure you are sending money to authentic and verified receivers.
- 💬 **Message Scanner**: Detect fraudulent patterns in suspicious SMS or WhatsApp texts.
- ⚡ **Instant Risk Assessment**: Get immediate feedback with our intuitive trust scoring UI.
- 🎨 **Premium Modern Design**: Built with a sleek, vibrant, and responsive user interface featuring micro-animations and glassmorphism.

---

## 💻 Tech Stack

- **Markup & Styling**: HTML5, CSS3 (Custom Variables, Flexbox, Grid)
- **Logic & Interactions**: Vanilla JavaScript
- **Architecture**: Static Frontend site (No complex build tools required)

## 🛠️ Local Setup & Installation

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/SanjivaniWawdhane/infraud.org.git
   ```

2. **Navigate to the project folder:**

   ```bash
   cd infraud.org
   ```

3. **Run a local server:**
   Since it's a static frontend app, you can use any HTTP server. For example, using Node.js:
   ```bash
   npx http-server
   ```
   _(Alternatively, simply open the `index.html` file in your preferred web browser.)_
